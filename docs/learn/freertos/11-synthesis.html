Ten rules

  1. Every task blocks in every loop pass.
  2. Priority follows the deadline, not the importance.
  3. Periodic means vTaskDelayUntil.
  4. Never busy-poll a flag: block on a queue, bit or notification.
  5. Pass data by copy through queues; no globals between tasks.
  6. State in a mailbox, commands in a queue, events in bits.
  7. Clear result bits before starting what you will wait for.
  8. One owner per resource; if you must share, use a short mutex.
  9. Stack sizes are in bytes on ESP-IDF: measure them.
  10. Pin the control loop to its own core; write flash only when the robot is still.
