FreeRTOS, the Hard Way

A complete course on FreeRTOS, built on a real robot: micro_farr (ESP32-S3, ESP-IDF v6.1). Every timeline is live: predict first, then step through it and break it. Every number comes from this project.

The robot

The one sentence. Split the work into tasks that block until their moment, let the scheduler always run the most urgent ready task, and connect the tasks only through queues, mailboxes and event bits.
